# Shared threads: traceability matrix

Status: written 2026-11-21 against the integration worktree, while other lanes were still
landing (member approval and the no-caps changes). Each story of the Workspaces feature
(code: rooms) maps to the tests that prove it. The design is
[2026-11-21-shared-threads-design.md](2026-11-21-shared-threads-design.md).

Personas: Alice (staff, creates), Bob (colleague, shared), Vera (company viewer), Dana
(company admin), Hal (parent-company admin), Carol (no access).

How to read it:

- Python tests are `path::Class::test_name`. Vitest and Playwright tests are
  `path › describe › test title`.
- Layers: U unit, I integration (Postgres), B bridge API, V Vitest, E Playwright real
  stack, M Playwright mocked. A Python test counts as I when its module or decorator marks
  it `integration`, or when it uses the Postgres fixtures. Bridge tests count as B.
- Dry-run step: the numbered tests in `app/e2e-stack/two-users.spec.ts`. Steps 9 and 10
  call `expectedToFailUntil(...)`: they fail until the member-approval lane merges, then
  the mark comes off.
- A test is cited only when its body asserts the behaviour. No test that asserts a cap is
  cited as proof of anything; those are listed under "Tests to replace".
