## Performance experiments

The [cloud-only ten-second allowance with isolated timeout health](../../bench/runtime/uat-runtime-cloud10-health-isolated-report.json) passed 30/30 non-streaming requests on product `e988eb920b9`: p95 22.049 seconds, 95% bootstrap interval 20.178–24.892, zero duplicates and post-return calls. Selected models and local fallback timeout were unchanged. Recorded cost excludes unknown usage from eleven calls without results. This is a test-only policy, not a promoted product default.

That result does not qualify streaming chat: the native streaming path bounds connection creation separately from consumption. [Three explicit streaming diagnostics](../../bench/runtime/uat-runtime-cloud10-streaming-diagnostic-report.json) passed on the latest product, taking 13.608, 9.446 and 6.449 seconds, with one matching task and the additional calculation each. Three samples cannot qualify p95. The [normal-streaming thirty-request screen](../../bench/runtime/uat-runtime-default-streaming-cohort-report.json) has finished and failed: 29/30 correct, p95 **47.532 seconds** (95% interval 28.314–60.008), five over 30 seconds and one deadline failure before task dispatch. No duplicate tasks or post-return model calls occurred. Its older telemetry observes opening only; unknown stream usage remains explicit. A test-only allowance covering both opening and consumption passes fifteen contracts and is entering three-request diagnostics. No default is promoted.

Earlier failed populations remain preserved: full-catalogue default p95 33.872 seconds, deferred tools p95 39.362 seconds, all-model ten-second allowance p95 30.046 seconds. The eight-second experiment was stopped and rejected after three failed requests. No installed timeout or deferred-tool setting has been changed.
