The new `org_overview` tool reports runs, failures, cost, stuck agents and overdue work for every tenant a run may reach; CRM and run-history tools accept an optional `tenant`, the five cross-tenant writes accept `dry_run: true`, and a manifest can set `v2.child_tenant_access: true` for unattended runs. A tool call over the per-minute limit now waits for room instead of failing, the default rises from 30 to 60 a minute, and `read_file` on a directory returns its entries instead of an error. Two behavioural rules change: a refusal is relayed in plain words without throttle or gate names, and in a conversation an agent leads with the answer, looks up what the platform holds rather than asking, and says how old a record is.
