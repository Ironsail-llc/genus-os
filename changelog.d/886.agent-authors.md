`read_file` on a directory now succeeds: it returns the directory's entries with `"is_directory": true` and a note, instead of an "Is a directory" error. The shipped workspace guide and the starter instructions for `main` now point at the files setup actually creates, read daily notes and long-term memory only if they exist, and use `list_agent_schedules`, `list_agent_runs` and `list_tasks` for fleet awareness. See [Tools](TOOLS.md).

The new `org_overview` tool reports runs, failures, cost, stuck agents, overdue schedules and overdue tasks for every tenant the run may reach. CRM and run-history tools accept an optional `tenant` to run in a child tenant, and the five cross-tenant writes accept `dry_run: true` to show what they would change. A manifest can set `v2.child_tenant_access: true` so the agent's unattended runs reach the children. See [Tools](TOOLS.md#child-tenants-org_overview-the-tenant-argument-and-dry_run).
