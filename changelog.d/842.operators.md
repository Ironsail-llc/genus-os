The runtime image now carries `git`, and can carry a checksum-pinned Claude Code
CLI when it is built with the `CLAUDE_CODE_VERSION` and per-architecture
`CLAUDE_CODE_SHA256_*` build args. On hosts that cannot run bubblewrap,
`ROBOTHOR_CODING_SANDBOX=off` lets coding jobs run without Claude Code's Bash
sandbox; the default stays `required`. See [Tools](TOOLS.md).
