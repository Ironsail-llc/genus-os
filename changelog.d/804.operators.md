Finishing a run no longer holds up the engine while it publishes telemetry. The
Redis entry and the OTLP trace export now run in the background on shared
clients, so a slow or unreachable collector can no longer stall other chats and
runs. Failed, timed-out, aborted and interrupted runs now export their trace
too, with an error status and the reason, and the exported trace resource takes
the standard `OTEL_RESOURCE_ATTRIBUTES` and `OTEL_SERVICE_NAME` settings. See
[Observability](OBSERVABILITY.md).
