Datadog monitors can now report to Genus: point a Datadog webhook at the
`/api/webhooks/datadog` channel with the new `header_secret` scheme, and tag
each monitor with `org:<tenant id>`. Each state change is recorded once as a
`datadog.alert_received` audit event in that tenant, with who it would notify
and the read-only triage run it would start. `ROBOTHOR_DATADOG_ALERTS_MODE`
stays `dry_run` for now, so nothing is delivered and no run starts. See
[Observability](OBSERVABILITY.md#datadog-alerts-into-genus) for the payload to
paste into Datadog.
