Datadog monitors can now report to Genus through the `/api/webhooks/datadog`
channel, using the new `header_secret` scheme, once each monitor is tagged
`org:<tenant id>`. Each state change is recorded once as a
`datadog.alert_received` audit event in that tenant, with who it would notify
and the read-only triage run it would start. Alerts are recorded, not
delivered: nobody is notified and no run starts until delivery arrives in a
later release. See [Observability](OBSERVABILITY.md#datadog-alerts-into-genus)
for the payload to paste into Datadog.
