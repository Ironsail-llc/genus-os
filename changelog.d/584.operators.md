A command's output is no longer silently cut short. `exec` still shows the
first ~4,000 characters, but the whole stream is now written to a file under
`.robothor/exec/` in the agent's workspace whose path comes back in
`stdout_path`, and the marker in the visible part names it — so nothing an
agent asked for is destroyed, and a run can go and read the rest. Three new
ladder settings ship on `observe`, where they log what `enforce` would do and
change nothing an agent sees: `ROBOTHOR_TRUNCATION_LEDGER_MODE` (a run is told,
once, about output it never read back), `ROBOTHOR_ACT_OBSERVE_MODE` (a run that
changed something and never looked again is told so) and
`ROBOTHOR_VERDICT_COMMITMENT_MODE` (a triage deliverable should carry one
verdict per item). All three appear in the
[Configuration reference](reference/configuration.md) and on the Controls page,
and each writes an `agent_guardrail_events` row on `observe` so the evidence
exists before the rung moves.
