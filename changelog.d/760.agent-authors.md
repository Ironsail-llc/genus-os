Two read-only tools answer questions about the operator's n8n automations: `n8n_list_workflows` lists them with failure counts, the last error and links, and `n8n_recent_failures` lists failed executions in a time window. Both read the n8n monitor's snapshot, never call n8n, and return `not_configured` while the monitor is off. Failures reach the main agent as `workflow_failure` notifications with `source: n8n`. See [Tools](TOOLS.md#n8n-automations-n8n_).
