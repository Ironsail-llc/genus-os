With `ROBOTHOR_CONFIG_CACHE` on, a run reuses the agent's merged and validated manifest, its adapter configs and the digest of each pinned adapter binary, and reads them again only when a file changes, a plugin sync or reload runs, or the defaults are reloaded. The setting is off by default. With it on, an edited adapter YAML reaches runs within one extension-watcher poll; see [Connectors](CONNECTORS.md).
