With `ROBOTHOR_CONFIG_CACHE` on, a run reuses the agent's merged and validated manifest, its adapter configs and the digest of each pinned adapter binary. It reads them again only when a file or a `${...}` value it names changes, plugins are reloaded, or the defaults are reloaded. The setting is off by default; see [Connectors](CONNECTORS.md) for what it means for adapters.
