A parent tenant's agent can now use the tools that live in a child tenant's engine, the child's own plugin tools included: `org_tools` shows what each company has connected, `org_tool_read` looks something up there, and `org_tool_write` acts there for the verified owner, with a dry run that executes nothing. Every call is checked by the home engine, the bridge and the child's engine, and audited under both tenants. The Command centre shows a Connected block on each company card. See [Tools](TOOLS.md).
