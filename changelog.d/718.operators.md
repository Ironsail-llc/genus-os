CVE-2026-114612. Agents set to `max` reasoning effort now ask GPT-5.6 models
for `xhigh` rather than `high`, which can show in cost and latency. LiteLLM now
installs boto3 as one of its own dependencies, which makes the image slightly
larger. Upgrade as usual: see
