Context compaction has a hardened path behind `ROBOTHOR_COMPACTION_V2` (off by
default). It summarises with the agent's own model chain instead of a
platform-picked model, reclaims tool arguments, old tool results and media with
no model call first, updates its summary instead of rebuilding it, waits
`ROBOTHOR_COMPACTION_MIN_GAP_ITERATIONS` between compactions, and keeps the
conversation (the run's compaction step marked degraded) when no model can
summarise it. See [Configuration](reference/configuration.md).
