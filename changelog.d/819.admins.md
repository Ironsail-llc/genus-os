Context compaction summarises with the agent's own model chain (the fleet chain
when a caller has none) instead of a platform-picked model, and reclaims tool
arguments, old tool results and media with no model call first. It updates its
summary instead of rebuilding it and waits
`ROBOTHOR_COMPACTION_MIN_GAP_ITERATIONS` between compactions. When no model can
summarise, the conversation is kept and the run's compaction step is marked
degraded. See [Configuration](reference/configuration.md).
