A critical alert that Telegram cannot deliver, because it is not set up or the send failed, now goes to the channels listed in `ROBOTHOR_ALERT_FALLBACK_CHANNELS` (for example `email:you@example.com`), in order, and the engine log names the channel that delivered it. The new doctor check `alerts.delivery` fails with "no alert channel can deliver" when neither Telegram nor any fallback can send. Run `genus doctor --only alerts.delivery` after an upgrade to see where your alerts go. See [Configuration reference](reference/configuration.md) for the setting.
