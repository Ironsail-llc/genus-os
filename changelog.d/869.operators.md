The engine now writes one structured `event=tool_call` log line for every tool
call, naming the tool, the agent or workflow and its run, the outcome (`ok`,
`error`, `refused` or `deferred`), a short reason and the duration, so what an
agent did can be read back from the logs. Arguments and results are never
logged. See [Observability](OBSERVABILITY.md#one-log-line-per-tool-call) for the
fields.
