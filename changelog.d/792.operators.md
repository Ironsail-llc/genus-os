A container deployment can now point the dashboard's Logs page at its real logs: set `GENUS_LOGS_URL`, or the Helm value `logs.url`, to where this deployment's logs are viewed, and the page offers an **Open logs** link to it. The chart renders the variable on the bridge only when the value is set. The URL is shown to every operator, so keep it credential-free. See [Deployment](deployment.md#the-helms-observe-pages).
