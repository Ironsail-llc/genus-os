`memory-eval --world --answers` now scores memory on the answers a local model gives from each system's context, not on whether a retrieved row contains the gold string. It compares the product recall path, both as it returns today and filled to the token budget, against keyword-only, raw-history and full-context baselines at the same budget, with keyword-only as the reference. A judge grades the answers and is checked against planted wrong answers, hedges included, before every run. The report gives accuracy, confident-wrong rate, abstention, tokens and latency per stratum; see the memory benchmark baseline page for the recorded numbers.
