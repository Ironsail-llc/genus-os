`memory-eval --world --answers` now scores memory on the answers a local model gives from each system's context, not on whether a retrieved row contains the gold string. It compares the product recall path against keyword-only, raw-history and full-context baselines at the same token budget. A judge that is checked against planted wrong answers before every run grades the answers, and the report gives accuracy, confident-wrong rate, abstention, tokens and latency per stratum. See the memory benchmark baseline page for the recorded numbers.
