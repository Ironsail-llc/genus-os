Memories now strengthen by the outcome of the runs that recalled them: a run that completes gives a small credit to what it recalled, a run whose answer uses a fact's distinctive value gives a larger one, and a failed run weakens them, all bounded so repetition alone can never raise a memory. Recall ranking reads this utility in place of the raw retrieval count, and use now fades, so a fact recalled once long ago can be pruned again. Migration 180 adds four nullable columns to `memory_facts` without rewriting the table. See [Memory system](memory-system.md) for the formula and constants.
