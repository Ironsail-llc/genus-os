Memories now strengthen when a successful run's answer uses one of their distinctive values and weaken when the runs that recalled them fail; being recalled, even in runs that went well, no longer raises a memory, and recall ranking reads this bounded utility in place of the raw retrieval count. Use now fades, so a low-importance fact last used more than 90 days ago can be pruned again: expect the first deep maintenance pass after upgrading to retire such facts in one batch (a soft, reversible deactivation). Migration 180 adds four nullable columns to `memory_facts` without rewriting the table. See [Memory system](memory-system.md) for the formula and constants.
