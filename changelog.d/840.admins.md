An owner or admin can now hand the default chat agent an API key in chat and have it stored, tested and answered for with a fingerprint. It takes only a value from the person's own message that turn, from a registered owner or admin the channel verified; unregistered senders, members, sub-agents and scheduled runs are refused, and the refusal says which gate held and what opens it. Settings › Secrets can now remove a credential from the vault. See [Configuration](configuration.md).
