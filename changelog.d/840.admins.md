An owner or admin can now hand the default chat agent an API key in chat and have it stored, tested and answered for with a fingerprint. It takes only a value the person typed that turn beside the key's name, never one from a quoted message or an attached file, from a registered owner or admin the channel verified; unregistered senders, members, sub-agents and scheduled runs are refused, and the refusal says which gate held and what opens it. Settings › Secrets can now remove a credential from the vault, a handed-over credential is no longer kept in run checkpoints, and the engine log records a Telegram message's length instead of its text. See [Configuration](configuration.md).
