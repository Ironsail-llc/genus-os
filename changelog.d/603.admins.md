You can now set short-term goals that keep working until achieved, and long-term goals that pursue tasks and wait for dates or events. Every goal carries four ceilings — a token budget, a cost ceiling, a maximum number of runs and a deadline — so a goal that keeps reporting progress still stops and asks you before spending more; each is overridable when you set the goal and raisable when you resume it. Open Goals to enable execution for a tenant, inspect evidence, progress and remaining budget, or pause and resume work. An instance that leaves goal pursuit switched off pays almost nothing for it, existing session goals are unchanged until explicitly adopted, and the engine runs normally if the goal migrations have not been applied — see [Goal pursuit](features/goal-pursuit.md).
