You can now set short-term goals that keep working until achieved, and long-term goals that pursue tasks and wait for dates or events. Every goal is created with four ceilings — a token budget, a cost ceiling, a maximum number of runs and a deadline — so a goal that keeps reporting progress still stops and asks you before it spends more; each is overridable when you set the goal and raisable when you resume it. Open Goals to enable execution for a tenant, inspect evidence, progress and remaining budget, or pause and resume work. Existing session goals remain unchanged until explicitly adopted. See [Goal pursuit](features/goal-pursuit.md).
