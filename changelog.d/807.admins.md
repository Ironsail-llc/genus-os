A long chat message no longer has to pay for a separate planning call before
it is answered. With `ROBOTHOR_ROUTER_V2` on, a Telegram, webchat or
plugin-channel turn plans only in plan mode, when its agent's manifest asks
for planning, or when the message lists three or more steps, which saves one
model call on every long turn. It is off by default; see
[Configuration](configuration.md#when-a-chat-turn-pays-for-a-planner-call).
