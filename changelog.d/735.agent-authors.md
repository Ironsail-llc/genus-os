`read_file` now returns the text of PDF, Word, Excel and PowerPoint files
(including their macro-enabled variants, whose macros are never run) instead of
failing with a decode error, and any other binary file comes back as a size and
type summary. Telegram attachments in those formats reach the agent's first
turn as extracted text through the same code. Extraction stops at the
50,000-character cap and says so, so a very long document is not parsed whole.
See [Tools](TOOLS.md) for what each format yields.
