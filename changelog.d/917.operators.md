Upgrading applies a memory migration that adds the tables and columns the knowledge graph will use to link facts to entities by identity, and copies each existing edge's source fact into the new evidence table. On a memory of around a hundred thousand facts and edges it takes about a second, during which memory writes wait and graph reads pause briefly; nothing is rewritten and an older release still runs against the migrated database. See [Memory System](memory-system.md#graph-schema) for what each new table and column holds.
