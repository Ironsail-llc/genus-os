A run now gets pace-aware deadline notes at 50, 80 and 95 per cent of its ceiling, a repeat-call guard that answers an identical read of an unchanged file short, and exec timeouts bounded by the time actually left. All of it sits behind one flag, `ROBOTHOR_STEP_EFFICIENCY_MODE` — off, observe or enforce, observe by default — so it can be watched before it is enforced. See [Configuration](configuration.md) for how to set it.
