Genus now records what is installed in a plugin lockfile, so a plugin can be switched off without uninstalling it and the loader refuses one whose manifest changed underneath the engine. The verbs are `genus plugin list`, `info`, `enable`, `disable`, `sync` and `doctor`, and the doctor gains `plugins.lockfile`, `plugins.load` and `plugins.drift`. A damaged lockfile never blocks boot — it is reported, and the rows still readable still govern. See [Plugins](PLUGINS.md).
