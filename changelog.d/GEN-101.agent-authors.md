Agents can now start and report on workflows from a chat. `list_workflows`
shows each workflow's triggers, last run and recent failures, `run_workflow`
starts one with an optional payload (seen by its steps as `event.payload`) and
can wait up to two minutes for the result, and `workflow_runs` lists recent
runs with each step's status. See [Tools](TOOLS.md) for when to use
`run_workflow` instead of `spawn_agent`, and deny it to member roles in RBAC.
