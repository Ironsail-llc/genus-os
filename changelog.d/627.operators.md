Personal automation is now absent, not merely idle, on an instance that has not set `ROBOTHOR_AUTONOMY_ENABLED=true`: every `/api/autonomy/*` route answers 404 to a caller of any role, including the endpoints that store a payment card and set spending authority. The accidental-paste masking that rewrites card-shaped numbers in chat now applies only to messages a person typed, so a webhook body or a federated message carrying a tracking number or an IMEI reaches your agent unaltered. See [Autonomous execution](AUTONOMOUS_EXECUTION.md) for the switch.
