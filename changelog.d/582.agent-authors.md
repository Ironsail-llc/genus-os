A chain that ends on an `ollama_chat/` model is now sized against that model
once the cloud credentials are spent, so an agent living on the local tier
compacts at its own window rather than the primary's. When the messages still
do not fit, the engine drops the oldest tool results -- keeping the protected
head and the last user turn -- and says so in a `developer` turn, so an agent
that depends on a tool result should re-read it rather than assume it is still
above. Keep a task's requirements in the first few messages, where compaction
protects them; the model chain and its fallbacks are described on the
[Configuration](configuration.md) page.
