Setting who Google emails about an agent's events now saves the value you
picked. `ROBOTHOR_CALENDAR_SEND_UPDATES` offers `all`, `externalOnly` and
`none` on the Controls page, but the middle one was lower-cased on its way
through and read back as `all` — so the page showed a posture the engine was
not running. Its capitalisation is preserved everywhere now, and the same value
set is what the flag inventory declares, so a page can no longer offer a value
the API would refuse. See [Configuration reference](reference/configuration.md).
