A manifest can name `openai/gpt-6.2-sol`, OpenAI's GPT-6.2 Sol, and the run is sized and priced from its own registry entry, sent `reasoning_effort` rather than `temperature`, and billed at twice the price on the priority tier. The engine sizes it to 272,000 input tokens, where the provider's long-context price begins, so compaction keeps every request on the standard price. A manifest's `when:` clauses now apply to the run whose trigger they name, so a webchat or cron clause that sets `model.primary`, `model.fallbacks` or `model.service_tier` gives those runs their own chain while every other trigger keeps the fleet defaults; a clause in an existing manifest takes effect on upgrade. See [Agents, skills and plugins](enterprise/04-agents.md) for the trigger types and an example.
