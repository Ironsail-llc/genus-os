`analyze_image` now takes an optional `choices` list of 2–20 labels, and every
answered row comes back with a short `reason` saying what the model saw. With
`choices` a row carries a validated `choice` spelled the way you spelled it, and
a reply naming none of them is asked once more and then reported as that row's
error rather than squeezed into the nearest label. A spilled batch also returns
a `sample` of rows spanning the distinct answers, asking for `scan.png` when the
file is `scan.jpg` now reads the file instead of failing, and a relative path
that misses says which workspace root it was joined to. See [Tools](TOOLS.md).
