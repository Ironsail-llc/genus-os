Your agent can now recover output the engine had to cut. An `exec` result over
the window carries `stdout_truncated`, `stdout_chars` and `stdout_path`, and
`read_file` on that path returns the whole stream — so a listing whose tail used
to vanish is something the agent can page back, and that read is exempt from the
repeat guard. Prefer `genus_tools` inside `execute_code` over `curl` or `urllib`
when calling an API: a proxied call keeps its full response on the run's ledger
whatever the snippet prints, and `execute_code` now reports how many responses
the snippet never showed itself. Both contracts, and the rule that a
state-changing call invalidates what you observed before it, are in
[Tools](TOOLS.md).
