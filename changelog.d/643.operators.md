Owner commands run through `robothor-host-exec` can write under `/home` again (`ProtectHome=no`). That unit only, and the engine stays confined, so CLIs no longer fail with "Read-only file system" after they have done their work. `genus config get` now names the systemd drop-in or environment file that sets a value for each unit. `genus config set NAME VALUE --apply` changes it there: it writes a `zz-genus-config-*` drop-in, names any later drop-in that would keep winning (`--override` outranks it), reloads systemd and schedules the restart 15 seconds out. Reinstall the host-exec unit on upgrade. See [Configuration](configuration.md#when-a-systemd-unit-sets-it).
