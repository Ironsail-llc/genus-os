Restarting the engine no longer fails the Claude Code jobs it was running.
They used to end "budget exhausted" with their whole budget charged; now the
engine parks them and resumes them when it starts again. Reinstall the engine
unit (`KillMode=mixed`, see [Systemd Services](deployment.md#systemd-services))
to pick this up. PR reviews also no longer fail with
"head not found" when GitHub's pull ref lags behind the pull request
([PR reviewer](PR_REVIEWER.md)).
