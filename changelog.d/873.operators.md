A run that reaches the runaway-token hard cap (`ROBOTHOR_RUNAWAY_HARD_CAP_TOKENS`, 5,000,000) now stops: it is marked budget exhausted with the reason, its `budget_stop` step says `enforce`, the critical alert is raised, and the person who asked is told to narrow or split the request; raise the number if your runs legitimately need more. Compaction now shrinks a turn of many large tool results, and the "Proactive compaction" log line reports tokens before and after, with the reason when nothing could be reduced. Compaction also never separates a tool call from its results when an engine notice sits between them, which had made a fallback model reject the request and the run end with every model failed, and a failed model call now logs the provider's error text, redacted, next to its status.
