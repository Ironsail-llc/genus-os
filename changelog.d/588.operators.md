An instance with no local GPU can now use `view_image`. Previously only
`analyze_image` fell back to `ROBOTHOR_VISION_REMOTE_MODEL`, so agents in a
container were told there was no vision at all and went on to answer from
filenames instead. Each rung of the ladder gets `ROBOTHOR_VISION_LOOK_TIMEOUT`
seconds (45) and says which kind of failure it was, so a model that is
unconfigured, unreachable or out of credit no longer read alike — and note
that a remote fallback is billed per call, so leave the model unset where a
local one works. See [Tools](TOOLS.md#vision-view_image-and-analyze_image).
