The verdict-commitment control now reads a triage deliverable the way it is
written: a severity assigned by a section heading reaches the items filed under
it, so a report that says "here are the Critical ones, and here is each of
them" no longer reads as assigning no verdict at all, while an item that states
its own verdict is not double-booked by the section around it. An agent that
ignores an item's provenance marker must now name what outranks it — a message,
a time, a sender or system that confirmed something — because "the metadata was
disregarded" names nothing and is the sentence the rule exists to forbid. Every
run that reads such a deliverable now logs one line saying how many items it
inspected, how many carried a marker and how many findings came out, so an
inert result is visible rather than silent. See
[Agents](enterprise/04-agents.md).
