An agent that reads the same unchanged file twice now gets a short answer the second time instead of the whole file again. That was the intent before, but the guard resent the file whenever its earlier copy had fallen out of the model's context — which is most of a long run — so an agent could spend a large part of its budget re-reading its own work. A file that really changed is still re-read, so nothing is ever hidden from the model. See [Configuration](configuration.md) for the flag that governs it.
