The repeat-call guard was resending whole files once compaction had dropped its earlier answer, so on its own target shape it saved nothing. It now remembers what it resent and answers the next identical read short, while a changed file is still re-read, so the guard can never blind a model. A positive control, `genus doctor --only step_efficiency.guard`, fails against the old behaviour and passes against this one. See [Configuration](configuration.md) for the flag that governs it.
