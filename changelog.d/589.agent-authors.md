Agents run autonomously by default, and the platform now says so everywhere the
approval gate is described: `v2.human_approval_tools` plus the `human_approval`
guardrail is an opt-in for irreversible external actions — a refund, a payment
— not a default to add. When a gate does deny a call, the tool result now tells
the agent the gate is instance configuration and names the manifest key, so an
autonomous run can route around the tool instead of retrying into a prompt
nobody is there to answer. See [Tools](TOOLS.md#autonomy-first).
