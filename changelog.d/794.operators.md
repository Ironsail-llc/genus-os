A dashboard running more than one replica no longer signs operators out when two replicas refresh the same session at once: a refresh token spent less than 30 seconds earlier and presented again now returns the same new pair instead of a 401. Signed-out and revoked tokens get no such window, and no session affinity is needed. Upgrading applies migration 159, which adds two columns to `user_sessions`. See [Identity, roles and tenants](enterprise/02-identity.md#sessions-and-refresh).
