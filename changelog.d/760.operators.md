Genus OS can now watch an external n8n instance: set `ROBOTHOR_N8N_BASE_URL`, store an n8n API key in the vault and turn on `ROBOTHOR_N8N_ENABLED`. The engine then polls the workflows and failed executions, tells the main agent once about each failure, and raises one warning if n8n stays unreachable for three polls. It is off by default, and the `n8n.*` doctor checks report whether it is set up and keeping up. See [n8n monitoring](integrations/n8n.md).
