`read_file` and Telegram attachments now return the text of PDF, Word, Excel and PowerPoint files, stopping at the 50,000-character cap, and any other binary file comes back as a size and type summary. Agents can also write to Jira with `jira_create_issue`, `jira_add_comment`, `jira_transition_issue` and `jira_update_issue`. The Jira writes are opt-in, so name them in `tools_allowed` or `tools_opt_in`, and they are denied to the `user` and `member` roles. See [Tools](TOOLS.md) for what each format yields and the Jira key formats.
