A new flag, `ROBOTHOR_SANDBOX_PLAYGROUND` (off by default), stops a missing container runtime from failing runs that asked for a sandbox: an owner or admin's `exec` runs on the engine host with a note, and anyone else is told which gate stopped them and how to unlock it. Every `exec` result then says where it ran. `genus doctor --category sandbox` shows, per agent, where an owner's and a member's commands would go. See [Tools](TOOLS.md) for the result fields.
