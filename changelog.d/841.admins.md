A new flag, `ROBOTHOR_SANDBOX_PLAYGROUND` (off by default), stops a missing container runtime from failing runs that asked for a sandbox. With it on, an owner or admin's `exec` runs on the engine host with a note saying so. Anyone else is told which gate stopped them and who or what can unlock it. Every `exec` result says where it ran, and `genus doctor --category sandbox` shows, per agent, where an owner's and a member's commands would go. See [Guardrail flips](runbooks/GUARDRAIL_FLIPS.md) before turning it on.
