An agent can now chase the conversations it already reads: add an `ambient:`
block to its manifest (`watch`, `stalled_after`, `digest_at`) and it proposes a
nudge, a digest or a reply for each thread a person is still waiting on.
Each kind is held to its tier (`auto`, `approve` or `never`); a tier left out
is `approve` (`never` for replying in the thread), so nothing is sent without
a person approving it unless the manifest says `auto`. Every proposal is
recorded as an `ambient_proposal` step in the run detail and in a daily digest
file. See [Ambient follow-ups](AMBIENT.md).
