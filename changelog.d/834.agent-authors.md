An agent can now chase the conversations it already reads. Add an `ambient:`
block to its manifest (`watch`, `stalled_after`, `digest_at`, and a tier of
`auto`, `approve` or `never` for each of nudging the operator, sending a digest
and replying in the thread) and set `ROBOTHOR_AMBIENT=observe` to see what it
would send, recorded as `ambient_proposal` steps in the run detail, before
`enforce` sends anything. See [Ambient follow-ups](AMBIENT.md).
