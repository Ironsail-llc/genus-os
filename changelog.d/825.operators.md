Spend budgets no longer stop agents unless you set them: the fleet hourly cost cap (`ROBOTHOR_HOURLY_COST_CAP_USD`) and the runaway-token hard cap (`ROBOTHOR_RUNAWAY_HARD_CAP_TOKENS`) now record a `budget_stop` step, raise the existing alert and let the run continue. Set the limit explicitly, or set `ROBOTHOR_HOURLY_COST_CAP_MODE` / `ROBOTHOR_RUNAWAY_HARD_CAP_MODE` to `enforce`, to stop runs as before. Every budget stop, and your own durable stop, is recorded as a step and a telemetry event, and `genus doctor --only budget_stops.recent` counts the last day's stops. See [Configuration](reference/configuration.md).
