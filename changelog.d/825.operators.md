Spend budgets no longer stop agents unless you set them. The fleet hourly cost cap (`ROBOTHOR_HOURLY_COST_CAP_USD`) and the runaway-token hard cap (`ROBOTHOR_RUNAWAY_HARD_CAP_TOKENS`) now observe by default. A run that crosses one keeps going, carries a `budget_stop` step, and the existing alert is raised. Set the limit explicitly, or set `ROBOTHOR_HOURLY_COST_CAP_MODE` / `ROBOTHOR_RUNAWAY_HARD_CAP_MODE` to `enforce`, to stop runs as before. Every budget stop, and the operator's own durable stop, is now recorded as a `budget_stop` step and a telemetry event. `genus doctor --only budget_stops.recent` counts the last day's stops. See [Configuration](reference/configuration.md).
