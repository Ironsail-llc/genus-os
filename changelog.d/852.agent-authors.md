`genus plugin new` now starts a plugin with a `knowledge/` folder: a README on
keeping rules (code, changed by pull request) apart from knowledge (owned, dated
records with `owner`, `source` and `reviewed_on`), a sample advisory record, and
a `<name>.knowledge` doctor check that warns when a record is unreviewed or was
last verified more than 30 days ago. See [Plugins](PLUGINS.md).
