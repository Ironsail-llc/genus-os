The visual canvas now draws with a model you choose: **Canvas model** on the Providers page, saved by the same **Save default**, and left at "Same as the fleet default" it runs on whatever your fleet runs on. Model ids are dialled exactly as written, so the canvas works on any provider you hold a key for, not only OpenRouter ([Model providers](deployment.md#model-providers)); a `DASHBOARD_MODEL` value without a provider prefix is no longer read as an OpenRouter model. When generation fails, the canvas says why and its Retry asks for a new page, a page restored from an earlier session can be regenerated, and a failed update in the background shows its reason with a Retry instead of disappearing into the browser console.
