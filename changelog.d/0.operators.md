Memory decay now reflects use. Each time the `search_memory` tool or warm-up
recall returns a fact to an agent, its access count rises and its last-used
time is set, so the nightly prune no longer retires facts agents are reading on
age alone; facts never recalled are retired as before. Access history
backfilled into the decay shadow columns counts too, and facts strengthened by
a repeat mention are now scored by the importance judge. See
[Memory System](memory-system.md) for what counts as use.
