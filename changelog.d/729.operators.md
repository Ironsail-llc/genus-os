The container image now ships the Google Workspace CLI, so the mail, calendar and chat tools work in Kubernetes once you write an authorized-user OAuth file to a new `engine-google` Vault path and set `engine.googleWorkspace.enabled`; the engine mounts it read-only and never as an environment variable, and [the chart README](https://github.com/Ironsail-llc/genus-os/blob/main/helm/genus-os/README.md#google-workspace-credentials) covers minting and rotating it.
The image also moves LiteLLM from 1.92.2, which is affected by CVE-2026-114612, to 1.100.4, which pulls in boto3 and makes the image slightly larger.
Agents set to `max` reasoning effort now ask GPT-5.6 models for `xhigh` rather than `high`, which can show in cost and latency.
Upgrade as usual: see [Backup, restore and upgrade](enterprise/06-backup-upgrade.md#upgrading).
