The container image now ships the Google Workspace CLI, so the mail, calendar and chat tools work in Kubernetes once you write an authorized-user OAuth file to a new `engine-google` Vault path and set `engine.googleWorkspace.enabled`.
The engine mounts that file read-only and never exposes it as an environment variable; [the chart README](https://github.com/Ironsail-llc/genus-os/blob/main/helm/genus-os/README.md#google-workspace-credentials) covers minting and rotating it.
