Helm chat's Canvas now follows the conversation: when the agent draws a chart or breakdown, the canvas opens as the main view with chat docked beside it, including for replies that run longer than two minutes (previously cut off and recovered without their visual) and for views that contain links. Concurrent requests also share one session refresh, so operator views (Goals, Memory, Settings and the rest) no longer drop out of the sidebar when a session renews.
