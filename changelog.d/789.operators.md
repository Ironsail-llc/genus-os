An agent's tool success rate now counts every tool call that returned an error, including errors reported as an object rather than text. `log_interaction` reaches the bridge at `BRIDGE_URL` instead of the engine's own loopback, and a bridge refusal now says why (for example `agent not authorized` for an agent missing from `agent_capabilities.json`). `store_memory` and `record_resolution` refuse calls missing their required arguments, naming what was missing, instead of storing an empty fact.
