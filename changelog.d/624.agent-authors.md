Manifests gain four delegation and routing keys — `v2.spawn_allowed_agents`,
`v2.max_spawn_total`, `model.response_format` and `model.provider_order` — and
they now survive a heartbeat, worker or drain run instead of resetting to their
permissive defaults on exactly the runs nobody is watching. **Breaking:**
`tools_override` on a spawn may only narrow a child's declared `tools_allowed`;
a parent that used it to grant a tool now gets an error before the child starts,
and must change the child manifest instead. The ten `sales_*` tools and
`web_render` are opt-in: name one in `tools_allowed` to receive it, because an
agent that declares no tool list is no longer offered them. See
[Agents](enterprise/04-agents.md) and
[Tools](TOOLS.md#reading-javascript-pages).
