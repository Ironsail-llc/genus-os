Manifests gain four delegation and routing keys — `v2.spawn_allowed_agents`,
`v2.max_spawn_total`, `model.response_format` and `model.provider_order` — and
they now survive a heartbeat, worker or drain run instead of resetting to their
permissive defaults on exactly the runs nobody is watching. **Breaking:**
`tools_override` on a spawn may no longer grant; it narrows a child that
declares `tools_allowed` to a subset of that list, and it cannot hand a child
that declares none any of the opt-in tools. The ten `sales_*` tools and
`web_render` are those opt-in tools: name one in a manifest's `tools_allowed`
to receive it, because an agent that declares no tool list is no longer offered
them. See [Agents](enterprise/04-agents.md) and
[Tools](TOOLS.md#reading-javascript-pages).
