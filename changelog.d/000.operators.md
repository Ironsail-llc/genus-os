A caller using a service token that sends no `session_key` to the engine's chat endpoints no longer writes into the owner's main session: it gets a session of its own, `agent:<agent>:service:<service id>`. Probes and test turns should name their own key. The Telegram `/status` command shows each agent's 24-hour run figures again. See [Web chat](channels/webchat.md#probes-test-turns-and-other-service-callers).
