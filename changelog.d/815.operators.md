The chat stays smooth while a reply streams into a long conversation: earlier
messages are no longer re-rendered on every streamed word, and the view only
follows new text while you are at the bottom. Sending to a named agent no
longer asks the bridge for the full agent listing on every message; the
dashboard keeps each caller's listing for `GENUS_CHAT_AGENT_CACHE_TTL_MS`
(30 seconds by default, `0` to turn it off). See
[Configuration reference](reference/configuration.md).
