A plugin's patch onto an agent another plugin ships is no longer lost when that
agent's own plugin is synced, reinstalled or upgraded: the agent is re-rendered
with every installed plugin's patches applied again, in a stable order, whichever
plugins a sync touches. `genus plugin sync --check` reports a patch that is not in
effect without changing anything. See [Plugins](PLUGINS.md#composable-patches-append-and-detach).
