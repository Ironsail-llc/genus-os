A tenant can now claim email domains (`genus tenant set-domains acme-child-a example.com`).
A new SSO user from a claimed domain is provisioned into that tenant rather than the default one.
`genus tenant move-account --email alice@example.com --to acme-child-a` moves an existing account
and every row linked to it in one transaction, revokes its sessions, and audits the move. Run it
with `--dry-run` first. See the [CLI reference](reference/cli.md) for every flag; the tenant
hierarchy runbook in the repository walks through creating a child tenant end to end.
