Files can be attached to a message in the web chat: use the paperclip, paste a screenshot, or drop files on the composer. Images and text, Markdown, CSV, JSON or PDF files up to 5 MB each, three per message, reach the agent with their paths in the same inbox Telegram uses, and a credentials file such as `credentials.json` is kept but never read. See [Attaching files](channels/webchat.md#attaching-files).
