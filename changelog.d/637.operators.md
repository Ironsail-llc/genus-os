Run `genus claude-code login` once to give the instance's coding jobs a Claude Code subscription token; it is stored in the vault and proved with a one-turn call, and `genus claude-code status` repeats the proof. Apply migration 144 (`coding_jobs`) before restarting the engine: interrupted jobs resume on the next start. `genus doctor` reports the new `claude_code.ready` check, which skips on an instance that never set the driver up. See [Tools](TOOLS.md) for where worktrees live and what a job may read.
