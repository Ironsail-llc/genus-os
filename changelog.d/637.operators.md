Coding jobs use the Claude Code login the engine's user already has on the host; add `~/.claude` and `~/.claude.json` to the engine unit's `ReadWritePaths=` so it can refresh. On a host with no such login, `genus claude-code login` stores a subscription token in the vault instead (a stored token wins). `genus claude-code status` proves either with a one-turn call. Apply migration 144 (`coding_jobs`) before restarting the engine: interrupted jobs resume on the next start. `genus doctor` reports the new `claude_code.ready` check, which skips on an instance that never set the driver up. See [Tools](TOOLS.md) for where worktrees live and what a job may read.
