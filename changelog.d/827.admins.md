A burst of scheduled and hook runs no longer has to delay a person's reply.
With `ROBOTHOR_EXECUTION_LANES=1` interactive turns (Telegram, the chat panel,
Slack, plugin channels, the CLI) and background work run in separate lanes,
each with its own run limit (`ROBOTHOR_MAX_CONCURRENT_INTERACTIVE`,
`ROBOTHOR_MAX_CONCURRENT_BACKGROUND`) and thread workers, and a local inference
slot is kept for interactive requests. Off by default; occupancy is on
`/health` and `/metrics`. See [Configuration](configuration.md).
