A burst of scheduled and hook runs no longer delays a person's reply: interactive turns (Telegram, the chat panel, Slack, plugin channels, the CLI) and background work now run in separate lanes, each with its own thread workers.
Background runs are capped by `ROBOTHOR_MAX_CONCURRENT_BACKGROUND` (default 2), interactive turns stay uncapped unless you set `ROBOTHOR_MAX_CONCURRENT_INTERACTIVE`, and a local inference slot is kept for interactive requests.
Occupancy is on `/health` and `/metrics`; see [Configuration](configuration.md).
