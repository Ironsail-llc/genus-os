Pictures and files now work both ways over Telegram. Send your assistant a photo, a document, a voice note or a whole album and it keeps the file instead of describing the first frame and forgetting it — the copy lands under `inbox/telegram/<chat>/<date>/` in your workspace, it can open it, and it tells you plainly when the model you are on cannot actually see an image. Ask for a file back and it sends one; a document goes up to 50 MB and a photo up to 10 MB, while anything you send that is over 20 MB is refused by Telegram before it reaches the bot, and the assistant says so rather than going quiet. Kept files are pruned after `ROBOTHOR_INBOX_RETENTION_DAYS` (30 by default), and anything that arrived named or shaped like a credential is quarantined so no tool can read it back out; see [Telegram channel](channels/telegram.md).
