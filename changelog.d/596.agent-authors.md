The engine now reads skills from two places: the bundled library it ships, then
the instance's own directory, where every `create_skill`, `update_skill` and
`skill_archive` write lands. A skill in the instance shadows a bundled one of
the same name, so `create_skill` and `update_skill` now refuse a name the
platform ships unless you pass `shadow_bundled=true`, and `list_skills` and
`skill_view` report `origin` and `shadows_bundled` for every skill. Archiving
an overlay reports `unshadowed_bundled` rather than `archived` — the bundled
skill is live again and nothing was retired. See
[Platform vs Instance](PLATFORM_INSTANCE.md).
