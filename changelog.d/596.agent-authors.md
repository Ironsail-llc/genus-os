The engine now reads skills from two places: the bundled library it ships, then
the instance's own directory, where every `create_skill`, `update_skill` and
`skill_archive` write lands. A skill in the instance shadows a bundled one of
the same name, so revising a bundled skill leaves the shipped file untouched and
writes the new revision beside it. Each skill's `meta.json` records which layer
it belongs to as `origin`, and a skill marked `instance` can never be committed
into the bundled library. See [Platform vs Instance](PLATFORM_INSTANCE.md).
