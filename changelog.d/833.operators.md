The engine now reads permission rules and the durable-stop state once per agent
loop iteration instead of before every tool call, so an iteration with ten tool
calls costs one read of each instead of ten and eleven. A permission row changed
by hand with `psql` now takes effect within 5 seconds; a stop issued from the
dashboard or the API is still honoured at the next tool call. See
[Interactive request performance](runbooks/INTERACTIVE_REQUEST_PERFORMANCE.md#permission-and-stop-reads-per-iteration).
