The pr-reviewer now reviews any pull request it is asked to review: a GitHub
review request for its bot login, an operator `pr_review_intake(pr=...)`, or a
link in a review Chat space. This works in any repository its token can read.
`ROBOTHOR_PR_REVIEW_REPOS` now means only the repositories watched proactively
and their ticket prefixes. A requested pull request the token cannot read is
logged and listed under `unreadable`, never dropped silently. See
[PR reviewer](PR_REVIEWER.md).
