On a Microsoft 365 workspace the assistant now describes its mail and calendar tools, and its own account, in Microsoft 365 terms: "Message ID" rather than "Gmail message ID", and Teams or Google Meet for online meetings. Google instances read exactly as before. `genus doctor` names the Microsoft Graph email transport, and fails when no assistant mailbox is set. Autonomy's mailbox verification (reading a website's one-time code from the inbox) is switched off on Microsoft 365, because its anti-spoofing check only works on Gmail. The email agents now treat a thread id as opaque, so Exchange conversation ids work. See [Microsoft 365](workspace/microsoft365.md).
