The dashboard now reports its Core Web Vitals, one `web_vital` JSON line per metric on its standard output and an entry on the capped Redis stream `robothor:events:vitals`, with no tenant or user recorded. Set `GENUS_DASHBOARD_WEB_VITALS=false` to turn it off. A browser tab also stops reopening its live event stream on every re-render. See [Observability](OBSERVABILITY.md#dashboard-web-vitals).
