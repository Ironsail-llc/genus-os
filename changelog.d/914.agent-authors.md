Memory search now ranks every hit on one relevance scale, whichever path found
it. A fact matched only by keyword is no longer sorted last for lacking a vector
score, a natural-language question still matches by keyword when one of its
words is missing from the fact, and entity-expansion facts, insights and
episodes compete for the same `limit` instead of being appended after it. Each
result now carries `relevance`, `rerank_score` and the rank it held in each
search leg. See [Memory System](memory-system.md#retrieval).
