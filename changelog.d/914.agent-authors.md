Memory search now ranks every hit on one relevance scale, whichever path found
it: a keyword-only match is no longer sorted last for lacking a vector score,
and a natural-language question still matches by keyword when one of its words
is missing from the fact. Entity-expansion facts, insights and episodes compete
for the same `limit` instead of being appended after it, and a caller with a
restricted data scope no longer gets insights, episodes or chat turns, which
cannot be filtered by person. Each result now carries `relevance`,
`rerank_score` and the rank it held in each search leg. See
[Memory System](memory-system.md#retrieval).
