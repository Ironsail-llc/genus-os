A deliverable that was asked to decide is now also checked for two shapes it
used to pass: a verdict withdrawn a sentence later ("treated as a real
incident … if this is actually a test …"), and an item whose own metadata — a
`classification:`, `origin:` or `x-…` field carried in the run's tool results —
says it is not a real report while the deliverable files it as live work.
Fleet-wide behavioural rule 19 states the principle to agents: an item's own
provenance marker is evidence about that item, and a verdict that ignores it
must say what overrides it. `ROBOTHOR_VERDICT_COMMITMENT_MODE` still ships on
`observe`, so both shapes only record a row today — see the
[Configuration reference](reference/configuration.md).
