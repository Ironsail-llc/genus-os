The [Runs page](OBSERVABILITY.md#runs-in-the-helm--every-run-and-what-one-run-did) now reads `agent_runs` through an index on `started_at`, so its list and summary stay fast as run history grows. The migration builds the index with a brief write lock on `agent_runs`; on a large table, build it beforehand with `CREATE INDEX CONCURRENTLY IF NOT EXISTS idx_agent_runs_started_at ON agent_runs (started_at DESC NULLS LAST, id DESC)` and the migration will skip it.
