Adds the dashboard shell for shared workspaces: a rail beside the main
conversation on the chat view, a workspace view with its latest report edition,
past editions and conversation, and live updates. Until the rooms API is
served, the rooms list answers 404 and the chat view shows no rail; a workspace
link opens a "This workspace isn't available" page. Workspace chat refuses to
send unless the engine confirms the workspace, so it does nothing until the
engine serves rooms.
