A new setting, `ROBOTHOR_CACHE_LAYOUT_V2`, keeps the system prompt, tool list and earlier conversation identical from one turn to the next so model providers can serve them from their prompt cache. It moves the current-time line out of the system prompt into an engine note before the latest message, adds cache breakpoints on Anthropic direct, and sends no cache markers to OpenAI or Gemini, which cache on their own. It is off by default; see the [configuration reference](reference/configuration.md).
