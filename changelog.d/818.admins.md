The engine now keeps the system prompt, tool list and earlier conversation identical from one turn to the next, so model providers can serve them from their prompt cache. The current-time line and the per-run task record move out of the system prompt into an engine note just before the latest message. Anthropic direct gets cache breakpoints after the tools and before the last two turns, while OpenAI and Gemini get no cache markers and cache the stable prefix on their own. There is nothing to configure; cache reads show in each run's token counts in the Helm, described in [Observability](OBSERVABILITY.md).
