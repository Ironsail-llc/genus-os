`genus doctor` no longer suggests putting a human in front of a delete. The
check that reported ungated record-deleting grants was `recommended`, which
marked an instance `degraded` for running the way Genus OS is designed to run;
it is now `agents.approval_gate_available`, an `info` line that states the fact
and names the two manifest keys that switch the gate on if you want it. No
shipped agent template arrives with the gate armed any more. See
[Tools](TOOLS.md#autonomy-first).
