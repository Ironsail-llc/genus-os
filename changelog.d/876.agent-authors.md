A write whose outcome is unknown now holds back only a repeat of the same action: the same tool on the same target (a thread, a recipient), however it is worded, instead of every later call of that tool for a day. A refused write now says it was not sent, names the earlier action and says how it is cleared. A plugin can declare, for its own write tools, what each acts on and a read-back verifier that settles an unknown outcome, under `effects` in its `genus.tools` payload. See [Tools](TOOLS.md#writes-whose-outcome-is-unknown).
