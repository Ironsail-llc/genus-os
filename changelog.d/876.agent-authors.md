A plugin can now declare, for its own write tools, what each one acts on and a read-back verifier, under `effects` in its `genus.tools` payload. When such a write's outcome is unknown, only a repeat on the same target (the same thread or recipient, however it is worded) waits instead of every later call of the tool for a day, and the verifier can settle it; tools that declare no target keep the whole-tool wait. A refused write now says it was not sent, names the earlier action and says how it is cleared. See [Tools](TOOLS.md#writes-whose-outcome-is-unknown).
