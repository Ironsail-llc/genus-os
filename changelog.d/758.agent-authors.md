Code that sends through the email channel can now pass an HTML body and a per-send SMTP from-address. `html=` sends a plain-text and HTML alternative in one message on every transport, and `sender=` replaces the instance's from-address on SMTP (the Google and Microsoft 365 transports send as their signed-in account and ignore it). The do-not-contact check still runs first on every send. See [Email](channels/email.md#html-and-sender).
