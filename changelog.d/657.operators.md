The PR reviewer no longer strands a pull request when GitHub refuses a post and the author pushes again before the retry: the written review is dropped and the new head is reviewed, instead of the row sitting in `posting` for good. A review that only failed to post is retried after 5 minutes rather than an hour, GitHub 5xx retries now span about 85 seconds, and the reviewer's Telegram digest carries only `PR review …` lines — never the model's narration.
