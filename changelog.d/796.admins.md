Observe › Runs is now a page you can work from: a summary of runs, failures, deliveries and cost over the period you choose, filters for status, agent, trigger and period, and a full-width table with Load more. A run that chose not to send (silent, suppressed, no output, published) reads "no delivery expected" in a neutral tone, and only a send that failed is red. Selecting a run opens a drawer that explains it: what it was asked, which models it tried, tokens and cost, and each step with its tool input and output, timing and errors. See [Observability](OBSERVABILITY.md) for the delivery categories and the 30-day step retention.
