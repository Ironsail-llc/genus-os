Agents can run on Vertex AI: `vertex_ai/*` models authenticate with a Google service account through `VERTEXAI_CREDENTIALS`, `VERTEXAI_PROJECT` and `VERTEXAI_LOCATION`, and the install now ships the google-auth library litellm needs for that. Before this, a Vertex-only fleet failed every call with "Google Cloud SDK not found" while other providers worked. Which environment variable each provider family reads, and which engine-wide settings still name a provider, is now in [Deployment](deployment.md) under "Model providers".
