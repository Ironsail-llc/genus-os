The platform's bundled skills now ship inside the engine image and the wheel, so an engine whose workspace has no `agents/skills` directory still has all of them, `pr-review` included. A copy in the workspace or the instance skills directory still wins its name, so delete any bundled skill you copied there by hand to work around its absence, or it keeps shadowing the newer shipped version (`genus doctor --only skills.shadowed` lists them). A pull-request review that cannot start because the skill or the GitHub token is missing now fails visibly and is retried, instead of staying queued. See [Platform vs Instance](PLATFORM_INSTANCE.md).
