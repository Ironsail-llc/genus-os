The main agent can now take a coding task from a remote repository to a draft
pull request: `claude_code_repo_prepare` clones an allowlisted remote into
`ROBOTHOR_CODING_WORKSPACE`, Claude Code does the work in a verified job, and
`claude_code_publish` pushes the commit that passed verify, to allowlisted push
URLs only, and opens a draft PR for an owner or admin. It does nothing until you
set `ROBOTHOR_CODING_WORKSPACE` and `ROBOTHOR_CODING_REMOTES` (an empty allowlist
leaves nothing to clone or push to), and nothing merges.
See [Tools](TOOLS.md).
