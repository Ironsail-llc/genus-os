The main agent can now take a coding task from a remote repository to a draft
pull request: `coding_repo_prepare` clones an allowlisted remote into
`ROBOTHOR_CODING_WORKSPACE`, Claude Code does the work in a verified job, and
`coding_publish` pushes the job's branch and opens a draft PR for an owner or
admin. Everything is off until you set `ROBOTHOR_CODING_WORKSPACE`,
`ROBOTHOR_CODING_REMOTES` and `ROBOTHOR_CODING_PR_ENABLED`, and nothing merges.
See [Tools](TOOLS.md).
