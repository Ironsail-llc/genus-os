An instance can now review pull requests on its own: install the `pr-reviewer` agent and the two `pr-review` workflow templates, set `ROBOTHOR_PR_REVIEW_REPOS` (and optionally a Chat space and a bot login), and apply migrations 145 and 146. Each review is a read-only Claude Code job started by `pr_review_prepare` and posted exactly once by `pr_review_finalize`; the verdict is recomputed in code from the findings, so a review with a blocker or major finding — or a previous one the model did not report resolved — is never posted as an approval. Repository review rules are read from the base branch, and anything credential-shaped is redacted before posting. Migration 146 denies review posting, Claude Code and the `pr_review_*` tools to `user`/`member` callers, and the `github_*` review-write tools to `service`. Failed reviews retry on a new head or after `ROBOTHOR_PR_REVIEW_RETRY_COOLDOWN_MINUTES`; label skips are opt-in via `ROBOTHOR_PR_REVIEW_SKIP_LABELS`. Never run it on the same repositories as another review bot. See [PR reviewer](PR_REVIEWER.md) for setup and cutover.
