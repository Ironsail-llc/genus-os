Your instance can now review pull requests on its own: install the `pr-reviewer` agent and the two `pr-review` workflow templates, set `ROBOTHOR_PR_REVIEW_REPOS`, and apply migrations 145–147. A review with a blocker or major finding, or an earlier one not reported resolved, is never posted as an approval, and each review is posted exactly once. To match a review bot your team already runs, point `ROBOTHOR_PR_REVIEW_GUIDELINES_PATH` at your team's guidelines and list `owner/repo:PREFIX` entries so reviews check the linked Jira ticket's acceptance criteria; you can also ask the assistant to review one pull request. Never run it on the same repositories as another review bot — see [PR reviewer](PR_REVIEWER.md) for setup, cutover and parity.
