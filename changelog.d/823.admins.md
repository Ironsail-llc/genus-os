Chat replies can now arrive sooner. With `ROBOTHOR_EARLY_DONE=1`, the web
chat's `done` event and the Telegram reply go out as soon as the answer's text
is settled, and run finalization (telemetry, post-run bookkeeping, the run-row
write, history save) finishes in the background. It is off by default; see
[Web chat](channels/webchat.md) for what still runs before the reply.
