Several engines, one per tenant, can now share one Redis: each reads the event streams with its own consumer group, set by `GENUS_EVENT_CONSUMER_GROUP`, while the root engine keeps the default `engine` and the stream positions it already holds. Every published event now names its tenant and an engine acts only on its own tenant's events, with untagged events from before the upgrade still going to the root engine. See [Event Bus](event-bus.md#one-engine-per-tenant).
