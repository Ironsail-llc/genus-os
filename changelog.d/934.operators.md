Agents granted the new Datadog span and trace tools read spans through each
tenant's `spans` filter in `ROBOTHOR_DATADOG_SCOPES`, and a tenant with no
`spans` entry uses its `logs` filter. Before deploying, check every entry that
has only `logs`: a filter that excludes with a log-only facet (such as
`-source:...`) excludes nothing on spans, so give that tenant its own `spans`
filter. See [Observability](OBSERVABILITY.md#reading-datadog-from-genus).
