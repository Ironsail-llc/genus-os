Agents granted the new Datadog span and trace tools read spans only for a
tenant whose entry in `ROBOTHOR_DATADOG_SCOPES` has its own `spans` filter; a
tenant with only `logs` is refused span and trace reads. Before granting the
tools, add a `spans` filter (for instance the same service terms as `logs`,
without any log-only facet) to each tenant that should read them. See
[Observability](OBSERVABILITY.md#reading-datadog-from-genus).
