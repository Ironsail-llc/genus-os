Foundation for running the mail and calendar tools on [Microsoft 365](workspace/microsoft365.md): Entra app-only sign-in (certificate client assertion, with a client-secret fallback) and a Microsoft Graph client. The client keeps message ids stable and times in UTC, retries throttled reads but never writes, and follows paging only on Graph's own origin. Nothing uses it yet, and `ROBOTHOR_WORKSPACE_PROVIDER` stays `google`.
