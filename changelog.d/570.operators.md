Installing Genus OS is one line: `curl -fsSL https://ironsail-llc.github.io/genus-os/install.sh | bash -s -- --substrate compose`. Every download is pinned to a release tag, the compose files are validated before anything starts, and a piped run without `--yes` is a preview that writes nothing. The Helm chart is published to an OCI registry at each release, so a cluster install no longer needs a clone of the repository. See [Quick Start](quickstart.md).
