Skills your agents write for themselves are no longer stored inside the
platform's own skill library, where a checkout could delete them and a commit
could publish them. They now live in your instance's `brain/skills` directory,
ignored by version control and already covered by snapshots, with
`ROBOTHOR_INSTANCE_SKILLS_DIR` to put them somewhere else. Run
`genus skills migrate-instance --dry-run` once after upgrading to see which
existing skills move, then the same command without the flag to move them. See
[Platform vs Instance](PLATFORM_INSTANCE.md).
