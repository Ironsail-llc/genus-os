An instance can now review pull requests on its own: install the `pr-reviewer` agent and the two `pr-review` workflow templates, set `ROBOTHOR_PR_REVIEW_REPOS` (and optionally a Chat space and a bot login), and apply migration 145. Each review is a read-only Claude Code job; the verdict is recomputed in code from the findings, so a review with a blocker or major finding is never posted as an approval. Never run it on the same repositories as another review bot. See [PR reviewer](PR_REVIEWER.md) for setup and cutover.
