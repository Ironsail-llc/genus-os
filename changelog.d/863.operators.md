Amazon Bedrock is now a supported place to run a model, starting with the
dashboard canvas: Amazon Nova 2 Lite on the US profile can be chosen as the
canvas model on the Providers page. Bedrock uses the standard AWS credential
chain rather than a key, and `boto3` now installs with the engine. GPT-6 Luna
is also available as a fleet model. See
[Model providers](deployment.md#model-providers) for what the AWS identity
needs.
