An instance with no local GPU can now give its agents vision by setting
`ROBOTHOR_VISION_REMOTE_MODEL` to a vision-capable provider model, instead of
the Ollama model `ROBOTHOR_VISION_MODEL` names. Batch image analysis is bounded
by three new settings — how many images run at once, how long one image gets,
and how long the whole call gets — so a stalled vision backend cannot hold a
run open. A model your engine does not know can accept images is refused rather
than dialled. See [Tools](TOOLS.md).
