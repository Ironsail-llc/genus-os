An instance with no local GPU can now give its agents vision by setting
`ROBOTHOR_VISION_REMOTE_MODEL` to a provider model, instead of the Ollama model
`ROBOTHOR_VISION_MODEL` names. The model has to be one your engine's registry
declares able to accept images — anything else is refused rather than dialled,
because a provider answers an image sent to an unsupported model with an error
per image. Batch image analysis is bounded by four new settings: how many
images run at once, how long one image gets, how long the whole call gets, and
how much of the result comes back inline before the rest is written to a file.
See [Tools](TOOLS.md).
