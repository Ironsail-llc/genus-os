The cache and event bus is now Valkey, deployed per instance by the chart's own
subchart rather than Redis. Existing values files keep working unchanged: the
`redis.enabled` toggle still means "deploy the cache this chart ships", and the
services still read `ROBOTHOR_REDIS_*` because Valkey speaks the same protocol.
`valkey.enabled` is the canonical name going forward and overrides it, with the
Valkey server's own settings under `valkey.*`. See
[Deployment](deployment.md) for the chart's toggles.
