Memory generation no longer falls back to the local GPU on every write. When
the remote model slug an instance is pinned to has been retired upstream, the
request is now rewritten to that slug's live successor before it leaves the
process, and the Telegram `/model` picker offers MiMo V2.6 Flash and Pro in
place of the retired v2.5 entries. See
[Configuration](configuration.md) for where the fleet model chain is set.
