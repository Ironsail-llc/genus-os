The bridge now does less work on every request: engine calls share one
connection pool, and its four request middleware layers are now one, giving the
same answers and headers with nothing to configure. The engine serves the agent
list from a cached scan, re-read only when a manifest changes on disk or is
written, reconciled or synced through the engine. See
[Operating an instance](enterprise/07-operate.md) for the bridge's place in the stack.
