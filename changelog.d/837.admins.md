Setting `ROBOTHOR_CONFIG_CACHE` (default off) lets the engine keep each MCP
adapter's tool list for as long as its session lives, instead of asking every
server on every run. Adapters also connect concurrently, an HTTP MCP server
keeps one client for all its requests, and adapter sessions are opened in the
background when the engine starts. See [Connectors](CONNECTORS.md) for what
refetches the list.
