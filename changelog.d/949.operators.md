Remote tools between a parent tenant and its children have no on/off setting: a child offers only the tools its plugins declare remote, and an operator narrows them with the child's own roles and plugins. This release adds migration 184 (the remote write ledger and the new `parent_agent` role, denied everything until a child grants it a tool, which unattended reads from the parent run as) and one setting, `GENUS_ORG_REMOTE_ATTESTATIONS` (chart value `tenancy.remoteAttestations`), naming what the deployment attests for a child's tool that requires it. See [Tools](TOOLS.md) and [Deployment](deployment.md).
