Remote tools between a parent tenant and its children are governed by one setting, `GENUS_ORG_REMOTE_TOOLS` (`off`, `read`, `dry_run`, `full`; chart value `tenancy.remoteTools`), and unattended reads need a per-tool grant to the new `parent_agent` role, which is denied everything by default. This release adds migration 184 (the remote write ledger). See [Tools](TOOLS.md) and [Deployment](deployment.md).
