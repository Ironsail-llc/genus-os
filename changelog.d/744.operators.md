One Helm release can now run an engine per child tenant: each entry in the chart's new `tenants:` list gets its own engine, Service and workspace volume, which the bridge and dashboard can reach. The root engine now sets both tenant variables from the new `global.rootTenant` value, whose default of `default` changes nothing. If your values set `ROBOTHOR_TENANT_ID` or `ROBOTHOR_DEFAULT_TENANT` in `engine.env` to anything else, move that value to `global.rootTenant`, or the chart will refuse to render. See [Deployment](deployment.md) for where the tenant list belongs.
