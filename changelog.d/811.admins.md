A chat turn's warmup is cheaper without changing the text the agent sees:
memory blocks are read in one query, entity lookups are batched, and the
caller's identity details are reused across a conversation for up to 15
minutes. Where the database is slow enough to matter, the warmup sections are
built concurrently and joined in the same order; on a fast database they stay
sequential. Each section's time appears on the run as its own warmup step (the
Runs page in [Operate it](enterprise/07-operate.md)). There is no setting for
this; it is how every chat warmup runs.
