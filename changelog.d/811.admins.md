A new setting, `ROBOTHOR_WARMUP_PARALLEL` (off by default), makes the first
turn of a chat wait for the slowest part of its warmup instead of all of them
in turn: the sections are built concurrently and joined in the same order, so
the agent sees the same text. Memory blocks are read in one query and the
caller's identity details are reused across a conversation for up to 15
minutes. Each section's
time now appears on the run as its own warmup step. See
[Configuration reference](reference/configuration.md).
