Chat messages have a small action bar on hover or focus: copy (as markdown or
plain text), regenerate a reply, and edit one of your messages to send it again.
Code in replies shows its language, a copy button and highlighting, the command
palette follows the arrow keys, and **?** lists the keyboard shortcuts. Set
`ROBOTHOR_CHAT_HISTORY_PAGES` to show each history message's real time and load
messages older than the last 50. See [Web chat](channels/webchat.md).
