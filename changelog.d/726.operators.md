`genus agent search`, `genus agent install <slug>` and `genus agent publish` now reach the marketplace at programmaticresources.io; the previous default pointed at a parked domain, so hub installs could not succeed. The dashboard's Marketplace links now open there too. Set `PROGRAMMATIC_RESOURCES_URL` (CLI) or `dashboard.env.NEXT_PUBLIC_PROGRAMMATIC_RESOURCES_URL` (Helm) to use a different marketplace host. See [Quickstart](quickstart.md) for the install flow.
