Your agent can now do several things in one turn. Independent read-only tool
calls on the same turn run at the same time, and a new `execute_code` tool runs
a Python snippet that calls your agent's own tools through `genus_tools`, so a
loop over fifty items costs one turn instead of fifty. Grant `execute_code`
alongside `exec` in `tools_allowed`, and write "for each…" work as a snippet
rather than a call per item. Both are documented in [Tools](TOOLS.md), with the
exact rule for which calls may run together and what a snippet may reach.
