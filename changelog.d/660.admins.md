Calendar tools now work on Microsoft 365: with the workspace provider set to
`microsoft365` and the assistant's mailbox configured, the assistant lists,
creates (with Microsoft Teams meetings), edits, RSVPs to and cancels events in
Exchange Online, behind the same do-not-contact, scheduling-policy and
duplicate checks as on Google. Exchange always notifies attendees, so leave
`calendar_send_updates` at `all`. Mail and calendar share one Microsoft Graph
connection; ingestion and end-to-end verification are still landing, so do
not enable Microsoft 365 in production until the release notes say so.
See [Microsoft 365](workspace/microsoft365.md).
