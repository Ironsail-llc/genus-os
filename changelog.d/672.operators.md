Telegram replies now read cleanly on a phone: headings, lists, quotes and code render as Telegram formatting instead of raw Markdown, and a table is drawn natively (or as one card per row when that isn't possible). Long replies no longer fall back to raw `**` and `|` when split. Set `ROBOTHOR_TELEGRAM_RICH_MESSAGES=0` to turn off native tables — see docs/configuration.md#how-replies-look-in-telegram.
