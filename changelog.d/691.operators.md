A fresh install now gets a LiteLLM below 1.105.3. LiteLLM 1.106.0 fails every
model call with "No module named 'mcp'" unless the `mcp` package happens to be
installed. 1.105.3 also reports a 200,000-token window for Claude Sonnet 4.6
and Opus 4.7 on OpenRouter, which serves both at 1,000,000. If you upgraded
LiteLLM by hand past 1.105.2, reinstall Genus to pick up the cap; see
[Backup and upgrade](enterprise/06-backup-upgrade.md).
