The agents shipped in `templates/agents/` no longer run Google CLIs (`gog`, `gws calendar`) through `exec`. The briefings, the calendar monitor and the email classifier now reach mail and calendar only through the `gws_gmail_*` and `gws_calendar_*` tools, so they work on a Microsoft 365 instance and every call passes the same guards. A test now fails on any shipped template that names a Google CLI. Check your own agents for the same pattern before you switch providers: see [Microsoft 365](workspace/microsoft365.md).
