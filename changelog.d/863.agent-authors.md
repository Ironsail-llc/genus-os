An agent can now ask its provider for the faster, paid lane. Set
`model.service_tier: priority` in a manifest, or in the fleet defaults, and
every call a run makes asks for it: the agent loop and the planning,
verification and compaction calls around it. It reaches the OpenAI API today
and is sent to no other route, so it is safe on a chain with a fallback
elsewhere. See [Model providers](deployment.md#model-providers).
