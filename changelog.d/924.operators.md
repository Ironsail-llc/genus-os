Memory now applies one read rule everywhere a fact's text is returned: a fact private to a person, a member or an agent is recalled for its owner and for no one else, in search, the graph walk, the entity lookup and warm-up (migration 181 gives warm-up's entity recall function the same rule). Nightly segment retention and CRM identity sync run per tenant, bulk graph writes refresh planner statistics (migration 182), and the search graph walk has a 250 ms server-side budget. The graph recall leg is off by default in search and warm-up, since the evaluation showed it hurting conversation recall without helping multi-step questions.
