One slow database query no longer stalls every other chat session and agent on the engine. Identity, person and tenant lookups, manifest reads, checkpoints and run-end bookkeeping now run off the engine's event loop, and audit and guardrail event rows go through a single ordered background writer that is flushed at the end of each run and on shutdown. Nothing changes in what is recorded or how an instance is configured; see [Deployment](deployment.md) for the release flow.
