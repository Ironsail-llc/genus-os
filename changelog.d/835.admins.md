Deferred tool loading is now on by default: an agent with more than 40 tools is
shown its core tools (the platform's fixed set plus the tools it called in its
last 10 runs) and finds the rest with `tool_search`, so the main agent's tool
block drops from about 32,000 to about 6,600 estimated tokens per request on a
stock install. Set `ROBOTHOR_RIP_16_ENABLED=0` to send every schema again, or
`ROBOTHOR_DEFERRED_TOOLS_RECENT_RUNS` to change how many runs seed the core.
The new `tools.deferred_tools_reachable` doctor check reports a granted tool an
agent could not reach. See [Tools](TOOLS.md#deferred-loading).
