An agent with more than 40 tools is now shown its core tools (the platform's
fixed set plus the tools it called in its last 10 runs) and finds the rest with
`tool_search`, so the main agent's tool block drops from about 32,000 to about
6,600 estimated tokens per request on a stock install.
`ROBOTHOR_DEFERRED_TOOLS_THRESHOLD` sets the tool count and
`ROBOTHOR_DEFERRED_TOOLS_RECENT_RUNS` how many runs seed the core.
The new `tools.deferred_tools_reachable` doctor check reports a granted tool an
agent could not reach. See [Tools](TOOLS.md#deferred-loading).
