Agents can send a file: the new `send_file` tool takes a path inside the workspace, renders it as a photo or a document, and routes back to the channel the run came from unless you name a target. An inbound turn now carries an `attachments` list alongside the text — path, name, kind, mime, size, image dimensions and the channel ids — so a handler can act on the file rather than on a sentence about it. `view_image` reports `seen_by`, naming the model that actually looked, and refuses instead of silently dropping the image when the active model does not accept one. See [Telegram channel](channels/telegram.md) for the turn shape and the refusals `send_file` can return.
