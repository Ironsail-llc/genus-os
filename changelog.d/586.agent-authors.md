`analyze_image` now takes an optional `choices` list of 2–20 labels, and every
answered row comes back with a short `reason` saying what the model saw. With
`choices` a row carries a validated `choice` spelled the way you spelled it —
matching is equality on a case- and punctuation-normalised form, never a prefix
or a fuzzy match — and a reply naming none of them is asked once more and then
reported as that row's error. A spilled batch also returns a `sample` holding
one row per distinct answer, asking for `scan.png` when the file is `scan.jpg`
now reads the file instead of failing, and `resolved_from` means "the path you
asked for" in both vision tools. See [Tools](TOOLS.md).
