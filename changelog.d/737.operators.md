A tool call whose outcome was never confirmed no longer blocks that tool for good: shell commands, code runs, the browser and file writes are not held back at all, because the agent can check their result on the host. A reworded retry of a send, calendar change or other outside-world write still waits for the earlier call to be reconciled, but for 24 hours at most. After that, housekeeping releases the call and chat labels it as released automatically, not as an operator's decision. See [Durable engine execution](features/runtime-recovery.md#how-long-an-unknown-outcome-blocks-a-tool).
