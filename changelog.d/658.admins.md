The mail tools can now run against Microsoft 365: set `ROBOTHOR_WORKSPACE_PROVIDER=microsoft365` and `ROBOTHOR_M365_ASSISTANT_MAILBOX`, and the `gws_gmail_*` tools search, read, send, reply to and label mail in the assistant's Exchange Online mailbox, with every do-not-contact and duplicate-reply check still in place. A search that can't be translated exactly is refused rather than widened, and calendar tools still refuse under Microsoft 365. See [Microsoft 365](workspace/microsoft365.md) for the supported search syntax, the label mapping and how replies thread.
