Settings › Secrets now lists every credential the instance declares or holds. For each one it shows whether it is configured, which store holds it, when it last changed and which services read it. A credential whose last change is more than 90 days old is flagged for rotation, and the page never shows a value or a fingerprint. See [The Secrets page](configuration.md#the-secrets-page) for what it shows and how to rotate a credential with `genus vault set`.
