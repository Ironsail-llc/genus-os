A Helm deployment can now run Claude Code jobs, including the PR reviewer. Released images carry a pinned, checksummed Claude Code CLI and the bubblewrap sandbox it needs. `engine.coding.enabled` places the coding and review clones on the engine's workspace volume and switches to token auth from `CLAUDE_CODE_OAUTH_TOKEN` in the engine providers secret. Because the default pod security blocks the sandbox, `engine.coding.sandbox.relaxPodSecurity` is an opt-in that relaxes it for the engine container only. See [Deployment](deployment.md#claude-code-jobs-pr-reviewer).

A tenant cell runs these jobs only when its own `tenants[].coding` block enables them; nothing is inherited from the root engine.
