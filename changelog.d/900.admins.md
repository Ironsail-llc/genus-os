Staff can now work in shared workspaces: company-owned conversations that sit
below each person's main conversation, each with its own history, a saved
dashboard, linked tasks and the colleagues it is shared with. A report
workspace publishes an edition for an explicit period on a schedule, and
anyone it is shared with can open it, pick another period and carry on with
the agent; ask the main agent to build one, or use "New workspace". Nothing is
capped: each edition shows what its run cost, a workspace whose runs keep
failing pauses itself and says why, and a run that dies part-way is
recovered. See [Workspaces](WORKSPACES.md).
