Staff can now work in shared workspaces: company-owned conversations that sit
below each person's main conversation, each with its own history, a saved
dashboard, linked tasks and the colleagues it is shared with. A report
workspace publishes an edition of charts and commentary on a schedule, for an
explicit period, and anyone it is shared with can open it, pick another
period and carry on with the agent. Ask the main agent to build one, or use
"New workspace" in the dashboard. Nothing is capped: each edition shows what
its run cost, a workspace whose runs keep failing pauses itself and says why,
and a run that dies part-way is recovered. See [Workspaces](WORKSPACES.md).
