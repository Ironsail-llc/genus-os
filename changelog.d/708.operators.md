The event bus now connects to the same Redis as the rest of the engine: with `REDIS_URL` unset it uses `ROBOTHOR_REDIS_HOST`, `_PORT`, `_DB` and `_PASSWORD`, so a deployment that configures the cache through those settings no longer has its bus stuck retrying `localhost:6379` while hooks and readiness are healthy. `REDIS_URL` still overrides the settings for the bus when set, and a password with characters such as `@` or `/` now works. The precedence is described in [Event Bus](event-bus.md#connection).
