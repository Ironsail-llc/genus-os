Every tool call, model call and finished run now writes one `key=value` log line (`event=tool_call`, `event=llm_call`, `event=run_end`), a failed workflow step logs its error, every alert writes an `event=alert` ERROR line whether or not it was delivered, and a page no channel delivered is also POSTed to `ROBOTHOR_ALERT_WEBHOOK_URL` when that is set; reasons are cut short and have credentials, email addresses and phone numbers removed. `genus engine failures` groups the last day's failed, refused and denied tool calls and failed workflow steps by tool, agent and error, and the doctor check `manifests.unrestricted_role` lists agents that run with the allow-all default role. Streamed model calls now record their input and cached tokens (they recorded zero input before, so run totals and the runaway token cap undercounted interactive runs), a fallback model is no longer sent the primary's thinking blocks, and Python warnings are logged at WARNING rather than as raw error output. See [Observability](OBSERVABILITY.md) for the line formats.
