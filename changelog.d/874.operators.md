Every tool call, model call and finished run now writes one `key=value` log line (`event=tool_call`, `event=llm_call`, `event=run_end`), a failed workflow step logs its redacted error, every alert writes an `event=alert` ERROR line whether or not it was delivered, and a page no channel delivered is also POSTed to `ROBOTHOR_ALERT_WEBHOOK_URL` when that is set. `genus engine failures` groups the last day's failed, refused and denied tool calls and failed workflow steps by tool, agent and error, and the doctor check `manifests.unrestricted_role` lists agents that run with the allow-all default role. A fallback model is no longer sent the primary's thinking blocks (some providers rejected that as a bad request), and Python warnings are logged at WARNING rather than as raw error output. See [Observability](OBSERVABILITY.md) for the line formats.
