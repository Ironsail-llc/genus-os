Vector searches now use pgvector's iterative index scan by default whenever the
installed pgvector is 0.8 or later, so a search for one tenant or person returns
the rows it asked for instead of coming back short. Older pgvector builds are
detected and left as they were; set `MEMORY_HNSW_ITERATIVE=0` to turn the scan
off. See [Memory System](memory-system.md#stores).
