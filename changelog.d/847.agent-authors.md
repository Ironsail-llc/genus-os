`genus plugin new` now also writes `programmatic.json`, the listing a plugin
index reads, and a release workflow. Push a `vX.Y.Z` tag that matches the
version in `pyproject.toml` and `programmatic.json`, and the workflow builds the
wheel, checks it carries its plugin manifest, and publishes it with
`SHA256SUMS`. See [Writing a Genus plugin](PLUGINS.md) for the layout.
