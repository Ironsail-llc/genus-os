A human's role can now decide what their chat session is offered. With
`ROBOTHOR_ROLE_CAPABILITIES_ENABLED=1` each run records a capability tier
from the role (owner unrestricted, admin elevated, everyone else unchanged),
and at `ROBOTHOR_ROLE_CAPABILITIES_MODE=enforce` a verified owner or admin is
offered the opt-in tool families (Claude Code, `web_render`, Jira and GitHub
review writes, `run_workflow`) without the manifest naming them. `observe`
only records what it would unlock. See [Tools](TOOLS.md#what-the-humans-role-adds-capability-tier).
