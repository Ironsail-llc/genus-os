A human's role now decides what their chat session is offered, not only what
it is refused. On a verified interactive run an owner or admin is offered the
opt-in tool families (Claude Code, `web_render`, Jira and GitHub review writes,
`run_workflow`) without the agent's manifest naming them. Every other role, and
every cron, hook, workflow and sub-agent run, is offered exactly what it was
before, and RBAC still decides each call. See [Tools](TOOLS.md#what-the-humans-role-adds-capability-tier).
