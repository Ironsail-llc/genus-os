Two new settings help an agent stop saying "I can't" about things it can do. `ROBOTHOR_CAPABILITY_BLOCK_ENABLED` adds a "What you can do here" block to every agent's system prompt, listing what its tools and this instance's settings allow and, for the rest, the gate and what unlocks it. `ROBOTHOR_REFUSAL_PAYLOAD_V2` makes every refused tool call name its gate (`role`, `flag`, `allowlist`, `runtime` or `policy`) and its unlock, and tells the agent to relay both. `genus doctor --category capabilities --agent <id>` prints the same assessment, and the new `tools.inability_copy` check finds instruction text that tells an agent it cannot do something. Both settings are off by default; see [Tools](TOOLS.md#when-a-tool-is-refused).
