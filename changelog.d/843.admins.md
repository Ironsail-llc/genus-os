Agents stop saying "I can't" about things they can do. Every agent's system prompt now carries a "What you can do here" block listing what its tools and this instance's settings allow and, for the rest, the gate and what unlocks it, and every refused tool call names its gate (`role`, `flag`, `allowlist`, `runtime` or `policy`) and its unlock, which the agent is told to relay. `genus doctor --category capabilities --agent <id>` prints the same assessment, and the new `tools.inability_copy` check finds instruction text that tells an agent it cannot do something. See [Tools](TOOLS.md#when-a-tool-is-refused).
