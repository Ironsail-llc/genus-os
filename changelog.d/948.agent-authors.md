When a remembered value changes, recall shows the new value first and the old one right after it, marked "Earlier value, replaced <date>", and two values that disagree with nothing deciding between them are marked "Conflicting value, unresolved". A value is replaced only when the conflict judge, reading just the statement and told both facts' dates and sources, says it changed — and for things people hold several of (jobs, emails, phones, titles) only when the new statement itself says it replaced one. Hedged, temporary or instruction-like text never replaces a value, and a less trusted source never replaces or reinforces what a user said or an operator confirmed. See [Memory system](memory-system.md#changed-values).
