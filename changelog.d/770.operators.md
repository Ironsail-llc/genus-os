Save default on the Providers page, and the setup wizard's default-model step, now work when the bridge and the engine run in separate containers. The engine writes the fleet default model block to `_defaults.yaml` in its own manifest directory and reloads it before it answers, so the bridge no longer needs the workspace volume, and a successful save always means the fleet is running on the new model. See [Deployment](deployment.md#model-providers).
