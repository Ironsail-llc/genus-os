`genus doctor` has two new checks: `manifests.prompt_files` fails when a manifest names an instruction or bootstrap file that does not exist, and `identity.tenant_name` warns when the tenant's display name is empty, the seed's `Default Instance` or its own id, since agents name the organisation by it. A caller using a service token that sends no `session_key` to the engine's chat endpoints no longer writes into the owner's main session: it gets a session of its own, so probes and test turns should name their own key. The Telegram `/status` command shows each agent's 24-hour run figures again. See [Web chat](channels/webchat.md#probes-test-turns-and-other-service-callers) and [Deployment](deployment.md).
