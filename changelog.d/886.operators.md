`genus doctor` has two new checks. `manifests.prompt_files` fails when an agent's manifest names an instruction or bootstrap file that does not exist in the workspace, naming the agent and the path; the engine still skips such a file, and now logs it once per agent and path instead of on every rebuild. `identity.tenant_name` warns when the tenant's display name is empty, the seed's `Default Instance` or its own id, since agents name the organisation by it. See [Deployment](deployment.md).
