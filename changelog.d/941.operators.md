When memory search is asked for the knowledge graph (`include_graph=True`), the graph's connected facts now follow the search's own results instead of replacing them: a search for N results returns its N usual results unchanged plus up to two graph rows after them. Before this, a graph row could push the right fact out of a five-row result (date-specific questions lost it in 6 of 114 held-out cases). The graph leg stays off by default, because with the default small answer model it still costs some "where is X based" answers (4 of 40 on one split). See [Memory System](memory-system.md#is-the-graph-leg-on).
