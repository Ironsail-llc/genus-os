Memory search now walks the knowledge graph on every search and returns the connected facts closest in meaning to the question, each labelled with the path that relates it ("Related via Alice Smith → Example Co: ..."), so "where is Alice's employer based" finds the employer's address through Alice's job; warm-up still leaves the graph out. On the memory evaluation's held-out questions, multi-step questions answered correctly rose from about 2 to 15 of 40, and no kind of question lost answers. Two limits are known: a question about where a person is based is sometimes answered with a related entity's city, and for date-specific questions the right fact dropped out of the first five results in 6 of 126 cases while staying in the first ten. Each search spends one more embedding, about 40 to 50 ms; see [Memory System](memory-system.md#is-the-graph-leg-on).
