Memory search now walks the knowledge graph on every search and returns the connected facts closest in meaning to the question, each labelled with the path that relates it ("Related via Alice Smith → Example Co: ..."), so "where is Alice's employer based" finds the employer's address through Alice's job; warm-up still leaves the graph out. On the memory evaluation's held-out questions, multi-step questions answered correctly rose from about 2 to 15 of 40, and no kind of question lost answers. A search for N results now returns its N usual results unchanged plus up to two connected facts after them, so no result the search returned before is pushed out (before this, date-specific questions lost the right fact from the first five in 6 of 114 held-out cases). One limit is known: a question about where a person is based is sometimes answered with a related entity's city. Each search spends one more embedding, about 40 to 50 ms; see [Memory System](memory-system.md#is-the-graph-leg-on).
