Memory search now walks the knowledge graph on every search and returns the connected facts closest in meaning to the question, each labelled with the path that relates it ("Related via Alice Smith → Example Co: ..."), so "where is Alice's employer based" finds the employer's address through Alice's job; warm-up still leaves the graph out. A search for N results returns its N usual results unchanged plus up to two connected facts after them, so nothing it returned before is pushed out (before this, date-specific questions lost the right fact from the first five in 6 of 114 held-out cases). On the memory evaluation multi-step questions answered correctly rose from about 1 to 15 of 40, but questions about where a person is based are sometimes answered with a related entity's city: with a small 8B answer model that cost 4 of 40 such answers on one split. Each search spends one more embedding, about 40 to 60 ms; see [Memory System](memory-system.md#is-the-graph-leg-on).
