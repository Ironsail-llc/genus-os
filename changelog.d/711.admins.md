A webhook channel can now verify senders that sign Stripe-style
(`t=<unix seconds>,v1=<hex>` over the timestamp and the raw body) by setting
`signature_scheme: stripe_t_v1`. It can read the signature from a header you
name, and it can drop redelivered events by delivery id. Existing channels
behave exactly as before. See [Event Bus](event-bus.md#webhook-ingress) for
the fields.
