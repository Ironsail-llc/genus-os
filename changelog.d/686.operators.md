Continuous integration now installs the exact dependency set the published
image ships, rather than re-resolving it on every run, so an upstream release
can no longer turn the pipeline red without a commit. Upgrading the lock to
clear that drift also moves Pillow to a new major version and patches 32 known
vulnerabilities that were present in shipped images. The release gate no longer
fails a pull request because a previous release's deployment tag lags; that
check now runs where it can be acted on. See [Deployment](deployment.md).
