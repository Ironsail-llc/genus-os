The owner's assistant can now read the instance env file: every key and
ordinary value is shown, secret values are masked to their last four
characters, and free-text comments are hidden. Every other caller is still
refused.
Two new owner-only tools, `config_get` and `config_set`, read and change
settings the same way `genus config` does, so the assistant no longer has to
refuse a settings change it cannot see. See [Tools](TOOLS.md).
