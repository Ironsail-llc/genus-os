An agent whose model chain falls back to an OpenAI GPT-5 model now gets answers
from it: the engine sends OpenAI reasoning models `reasoning_effort`, following
the agent's reasoning-effort setting, instead of a `thinking` block, and no
`temperature`. A fleet whose primary is a Gemini model on Vertex AI now gets
answers from it too, because the engine no longer sends it the prompt-cache
markers and trailing engine turns that Vertex rejected. Gemini 3.8 Flash on
Vertex AI and GPT-5.6 Luna are now in the model registry, so their runs are
sized and costed correctly. See
[Configuration](configuration.md#provider-keys-slot-by-slot) for the provider
keys a fallback chain needs.
