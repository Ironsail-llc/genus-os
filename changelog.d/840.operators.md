A credential stored with `vault_set` is now redacted by its exact value, as its fingerprint, from chat history, stored chat messages, the run's task text and logs, so a key with no recognisable shape no longer survives in them. The live tool stream no longer carries `vault_set` arguments to the browser, and a `vault_set` reached through `tool_call` is redacted in the stream and in the recorded run step as a direct call is.
