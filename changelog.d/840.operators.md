A credential stored with `vault_set` is now redacted by its exact value, as its fingerprint, from chat history, stored chat messages, the run's task text and logs, so a key with no recognisable shape no longer survives in them. The live tool stream no longer carries `vault_set` arguments to the browser, and a `vault_set` reached through `tool_call` is redacted in the stream and in the recorded run step as a direct call is. Every tool result now passes the same redactor before it reaches the agent, the run's steps, the effects record, the live stream or a checkpoint, so a credential a command prints does not survive there either.
