A plugin tool schema can carry a `keywords` list inside its `function` block,
the words an operator would use for it; `tool_search` ranks on them and they
are stripped before the schema reaches a model. Most agents now reach a plugin
tool through search, so a schema with no searchable word is reported by
`genus doctor`. `tool_call` now also accepts `arguments` sent as a JSON string
of an object, which used to be reported as a tool crash, and refuses a
malformed wrapper with an error saying what to fix. Every control judges a
`tool_call` as the tool it wraps: hooks, guardrails, human approval and RBAC,
the `<untrusted_content>` boundary on an external tool's result and the
redaction of credential arguments, so a manifest that gates `issue_refund`
gates it however the model reaches it. See
[Plugins](PLUGINS.md) and [Tools](TOOLS.md#deferred-loading).
