The credentials that open the platform itself (the database and cache
passwords, the signing keys, the vault's key files, and connection strings such
as `DATABASE_URL`) no longer reach any child process an agent starts, whatever
`ROBOTHOR_EXEC_ENV_MODE` is set to, and no manifest can grant them. A command
that needed one of them must go through a tool instead. See
[Configuration](configuration.md) for the exec environment ladder.
