The credentials that open the platform itself (the database and cache
passwords, the signing keys, the vault's key files, connection strings such as
`DATABASE_URL`, and any `ROBOTHOR_DB_*` or `ROBOTHOR_REDIS_*` setting whose value
holds a password) no longer reach an agent's child processes or the browser's
Playwright driver, on any `ROBOTHOR_EXEC_ENV_MODE` rung, while lifecycle
`command` hooks keep the rest of the engine's environment as before. The GitHub
tools, the PR reviewer and Claude Code now read their tokens from the vault of
the tenant making the call, so a token stored for the root tenant is not
returned in a child tenant. An engine that authenticates to the database through
`PGPASSWORD` or `PGPASSFILE` alone now refuses to start: set
`ROBOTHOR_DB_PASSWORD` instead. See [Configuration](configuration.md) for the
exec environment ladder and its one known exception.
