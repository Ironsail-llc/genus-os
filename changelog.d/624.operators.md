Genus can now run a native sales pipeline — discovery, research, qualification,
contact review, drafting, approval and delivery — with every integration switch
off until you turn it on, and with no message leaving the instance without your
exact-message approval. An instance that never selects a sales release runs
nothing new, is advertised none of the new tools and is not reported unready
because of them. Migrations 126 to 138 must be applied before upgrading, and
because they are forward-only this release cannot be rolled back by reverting
the code alone. See [Native sales intelligence](SALES_INTELLIGENCE.md) for what
is implemented, what is still excluded, and the rollback constraint.
