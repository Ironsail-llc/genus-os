You can hand an agent to another instance: `genus agent export` writes a bundle with the manifest, the instructions, the referenced skills and a `requires` list, and `genus agent install` takes a path, a directory or a URL with a checksum. A credential literal anywhere in an export is a hard failure, and adapter values are collapsed to environment names before they are written. The Helm offers the same export as a Share button. See [Agent Builder](AGENT_BUILDER.md) for the bundle format and what `requires` checks.
