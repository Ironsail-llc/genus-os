The Workspace tool names (mail, calendar, chat) are now defined once, as tool
families in `robothor/engine/tools/constants.py`, and every guardrail,
verification, evidence, receipt and benchmark table derives from them instead
of carrying its own copy of the `gws_*` names. A ratchet test fails on any new
literal outside the canonical modules. Nothing changes in behaviour: every
table holds the same tools it did. This prepares the ground for a second mail
and calendar provider behind the same [tools](TOOLS.md).
