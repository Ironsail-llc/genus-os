A live smoke suite now checks the [Microsoft 365](workspace/microsoft365.md) provider against a real dev tenant, one test per open question about Exchange behaviour (sign-in, scope, threading, search, time zones, 412s, RSVPs, cancellations and delta resync). It never runs in CI. It runs only with `GENUS_LIVE_M365=1`, refuses any tenant not listed in `GENUS_LIVE_M365_TENANTS`, and can only touch the configured test mailboxes. Scrubbed captures can be turned into test fixtures with `scripts/m365_capture_to_fixtures.py`.
