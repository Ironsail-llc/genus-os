Agents can now read a pull request's diff, its changed files and a two-commit comparison with `github_pr_diff`, `github_pr_files` and `github_compare`. A manifest that lists them in `tools_allowed` can also post reviews and act on review threads. `github_create_review` keeps findings that point outside the diff in the review body, so they are never dropped. On the token user's own pull request it posts the verdict as a comment. `github_reply_review_comment` replies in a thread, and `github_resolve_threads` resolves only the threads opened by the reviews you name. See [Tools](TOOLS.md#github-pull-request-review) for the rules.
