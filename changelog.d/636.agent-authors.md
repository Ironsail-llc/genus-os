An agent can now hand a coding task to Claude Code and get back a verified commit instead of a claim. `claude_code_start` runs the task in its own git worktree; the engine runs your acceptance command itself, checks for a commit, and resumes the same Claude Code session with the failure until it passes or the round and budget limits run out. The tools are opt-in (`tools_allowed`, or the new additive `tools_opt_in` manifest key), and the `claude-code` skill describes how an orchestrator should use them. See [Tools](TOOLS.md) for modes, limits and evidence.
