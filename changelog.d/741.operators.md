A tool call whose outcome was never confirmed no longer blocks that tool for good: shell commands, code runs, the browser and file writes are not held back at all (a possible duplicate is the accepted trade-off), and a reworded retry of an outside-world write such as a send waits for the earlier call for 24 hours at most. After that, housekeeping releases the call and chat labels it as released automatically, not as an operator's decision. The assistant can also open files attached to email, from Gmail or Microsoft 365 alike: `gws_gmail_get_attachment` downloads one (up to 20 MB) into `<workspace>/inbox/email/` with the same quarantine and retention as Telegram attachments and reads PDF, Word, Excel, PowerPoint and text. See [Durable engine execution](features/runtime-recovery.md#how-long-an-unknown-outcome-blocks-a-tool) and [Tools](TOOLS.md).
