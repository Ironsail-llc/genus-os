On Telegram and in the Helm web chat, a message you send while the agent is still working now joins that task instead of waiting behind it. The agent picks it up at its next safe point: Telegram confirms with a 👀 reaction, and the Helm marks the message "Added to the running task". If the agent was already writing its answer, you get that answer and then a revised one that takes your addition into account. See [Telegram channel](channels/telegram.md#adding-context-while-the-agent-is-working) and [Web chat](channels/webchat.md#adding-context-while-the-agent-is-working).
