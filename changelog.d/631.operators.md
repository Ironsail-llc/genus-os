On Telegram, a message you send while the agent is still working now joins that task instead of waiting behind it. The agent picks it up at its next safe point, and a 👀 reaction confirms it arrived. If the agent was already writing its answer, you get that answer and then a revised one that takes your addition into account. `/stop` still ends the run. See [Telegram channel](channels/telegram.md#adding-context-while-the-agent-is-working).
