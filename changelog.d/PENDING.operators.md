`robothor memory-eval --benchmark longmemeval` (or `locomo`) now scores the memory system on the public long-memory benchmarks, with each benchmark's own judge prompts or metric, accuracy per question type, context tokens and latency. Download the data with `scripts/download_memory_benchmarks.sh`; `--dry-run` estimates the spend of hosted answer and judge models before anything is called, and one ingestion is reused by every system and answer model. See [Memory System](memory-system.md#public-long-memory-benchmarks) for how to run one and how to read the result beside published numbers.
