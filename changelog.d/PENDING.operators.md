`robothor memory-eval --benchmark longmemeval` (or `locomo`) now scores the memory system on the public long-memory benchmarks, with each benchmark's own judge prompts or metric, accuracy per question type, context tokens and latency; `--dry-run` estimates the hosted spend first and `--rescore` re-scores a saved report with no model call. Each report says whether every cell is product-parity (`search_memory_tool`, the agent's own tool path and defaults) or harness-only, measures evidence at the turns that hold the answer, records the reranker state per question, and ends with published results beside their conditions. A reranker that falls back to the fused order or is unavailable now logs a WARNING and is counted, instead of returning unscored rows silently. See [Memory System](memory-system.md#public-long-memory-benchmarks) for how to run one and read the result.
