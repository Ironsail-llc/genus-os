Memory search now walks the knowledge graph on every search and returns the connected facts closest in meaning to the question, each labelled with the path that relates it ("Related via Alice Smith → Example Co: ..."), so "where is Alice's employer based" finds the employer's address through Alice's job. Warm-up still leaves the graph out. On the memory evaluation, multi-step questions answered correctly went from about 1 to 15 of 40 with a 32B answer model on both splits, no kind of question worse; two "where is X based" questions are still answered with a related entity's city, and with a small 8B answer model four such answers were lost on one split. Each search spends one more embedding, about 40 to 50 ms. See [Memory System](memory-system.md#is-the-graph-leg-on).
