Memory search now walks the knowledge graph on every search and returns the connected facts closest in meaning to the question, not the most important facts of whatever the walk reached: "where is Alice's employer based" now finds the employer's address through Alice's job, without sharing a word with it. Upgrading applies migration 183, which adds one read-only database function beside the existing walk and rewrites nothing. On the memory evaluation's synthetic world, reworded multi-step questions went from 21 to 56 of 126 answered in the top five, with no other kind of question worse and about 30 ms more per search (one extra embedding); warm-up still leaves the graph out.
