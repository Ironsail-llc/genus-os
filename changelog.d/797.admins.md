**Settings › Config** opens much faster: the instance reads its config file once per page load rather than once for every setting. The sections appear as soon as the page knows which settings exist, and each section's values fill in a moment later. The browser keeps the list of settings for up to five minutes, so after an upgrade that adds a setting, reload the page once that window has passed ([Configuration](configuration.md#from-the-helm-without-a-shell)).
