With paired reviewers configured, the review status report now compares this
reviewer with each peer on every pull request it reviewed in the window: the
peer's verdict at the same commit, whether the two agree, and which findings
only one of them raised. An approve-versus-request-changes split, or a peer
that has stayed silent on a reviewed head, shows up as an alert. See
[Comparing a pair](PR_REVIEWER.md#comparing-a-pair).
