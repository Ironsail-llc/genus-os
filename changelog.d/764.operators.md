When the bridge cannot reach the engine, Settings › Providers now says so in terms you can act on: it names `ROBOTHOR_ENGINE_URL` and asks you to check that the engine is running and that the network path from the bridge to the engine is allowed, instead of printing "engine unavailable". If only the current fleet default could not be read, you can still choose a primary model and save it, and Save says why it is disabled when there is nothing to choose. Try again now re-reads the providers, the model catalog and the fleet default together. See [Configuration](reference/configuration.md) for `ROBOTHOR_ENGINE_URL`.
