Agents can now ask one question about up to 200 images in a single
`analyze_image` call. Each image is sent to a vision model on its own and only
the text answers come back, so sorting or labelling a folder of pictures no
longer costs a turn and a context full of image tokens per file — `view_image`
is still the tool for studying one picture yourself. Answers arrive in the
order the paths were given, one image that fails does not cost you the batch,
and anything resolving outside the workspace is refused before a model sees
it. See [Tools](TOOLS.md).
