`ROBOTHOR_VERDICT_COMMITMENT_MODE` now also records a classification
deliverable that hedges a verdict away, and one that contradicts an item's own
provenance marker without saying why. It still ships on `observe`, so nothing
reaches the model — the extra shapes show up as `verdict_commitment` rows in
`agent_guardrail_events` alongside the ones already recorded there, which is
the table to read before promoting the setting. See the
[Configuration reference](reference/configuration.md).
