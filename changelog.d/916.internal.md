The memory evaluation can now run against a generated, generic synthetic world
with `memory-eval --world`. The world has people and organisations with name
collisions and a hub, dated facts with sources and origins, CRM rows, documents
and long conversations. Cases are generated for multi-step, entity-confusion,
point-in-time, update, abstention, raw-detail, long-tenure and cross-tenant
questions. World runs use their own `memory-eval-world` tenant and refuse the
nightly suite's `memory-eval`, so the two never disturb each other.
