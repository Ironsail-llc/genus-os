"All models failed to respond" no longer reaches you while the local fallback
can still answer: each call's context budget now belongs to the model the
engine will actually reach, an overflow is shrunk and re-asked once instead of
being retried five times as a server error, and a run that truly cannot get an
answer says which providers failed, why, and whether the local tier was
reachable. After a top-up or a raised cap, run `genus secrets reload` -- the
new command that makes the running engine re-read its credentials and put
retired keys back in rotation without a restart, which is the only thing that
clears a six-hour quota cooldown early. Prove the tier before you need it with
`genus doctor --only models.local_fallback_ready`; the credential pool, the
reload and the new checks are on the
[Configuration](configuration.md) page.
