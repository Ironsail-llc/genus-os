An `http` business adapter can now authenticate to an MCP server that issues
OAuth client_credentials instead of a static token: give it an `auth:` block
with `type: oauth_client_credentials`, `token_url`, `client_id`,
`client_secret` and an optional `scope`. The engine mints and caches the token,
sends it as a bearer header, and re-mints once on a 401. See
[Connectors](CONNECTORS.md#native-mcp-servers-that-take-oauth-client_credentials).
