Desktop and browser helpers no longer inherit the engine's whole environment. Tools like `scrot`, `xdotool` and any application the desktop tools launch now start from the same filtered environment `exec` already uses, so the fleet's decrypted credentials are not handed to every child process. `ROBOTHOR_EXEC_ENV_MODE` still defaults to `observe`, which changes nothing today and only logs, per agent, the names `enforce` would withhold — so this is a one-line flag change away from taking effect rather than a second code change. See [Configuration](configuration.md) for the exec environment modes.
